# Tang Primer 25K 32 声部中文波形电子琴

本工程把 ST7796S 显示屏、双 EC11、MCP3008 八通道压力采样和 I2S
32 声部音频合成集成在同一份 FPGA 码流中。

显示屏型号资料：
<https://www.lcdwiki.com/zh/4.0inch_SPI_Module_ST7796>

该模块使用 ST7796S、480×320 SPI 显示；`LED` 高电平点亮，`SDO(MISO)`
不参与当前显示逻辑。

## 音频功能

- MCP3008 连续扫描 `CH0～CH7`；
- 八路压力传感器共同驱动 32 个独立声部；
- 八个音符默认 `C4～C5`；`OCT +1` 时整体升高八度到 `C5～C6`；
- 踏板模式允许松开按键后继续叠加声音，同一音高可重复占用多个声部；
- 拨弦模式使用快速起音和零持续包络，按下后声音自然衰减，不需要松开按键；
- 每个声部有独立相位、压力幅度、ADSR 包络和触发时音色；
- 32 个声部满额后，新音会替换最早触发的声部；
- 声部力度经过慢速跟随，抑制轻压时的 ADC 抖动和低频幅度噪声；
- 复音增益按约 `1/√声部数` 保持整体响度，高复音时再平滑收小；
- 最终混音使用软限幅，普通单音保持纯正弦，仅在接近满幅时压缩峰值；
- 双 EC11 修改的音色、主音量和 ADSR 会直接进入音频引擎；
- 弯音、揉音和滑音直接修改振荡器相位增量，不是只改变屏幕文字；
- FPGA 内部提供原声、延迟、合唱和混响四种可选效果；
- 最终混合样本通过 MAX98357A I2S 输出，采样率约 48.8 kHz。
- MCP3008 全部八路轮询后，最坏压力到首个音频样本的仿真延迟约 3.96 ms。

## 界面

屏幕为 480×320 单屏中文仪表盘，显示：

- 当前参数与选中项；
- 真实混合音频波形；
- 2048 点实时频谱与当前基频标记；
- 基于真实音频和延迟相位的李萨如图形；
- MCP3008 `CH0～CH7` 八路压力；
- ADSR 包络；
- 音色、音量和拼音化技术参数的数值。

波形区域显示最近约 10.5 ms 的混合音频窗口，不是公式生成的示意波形。
相邻采样列之间会补画连接线，陡峭波形不会再断成散点。
每次采集从上冲过零点开始；完整的新缓冲区在下一帧起点整体切换，
连续刷新时波形相位一致，不会在画面中间拼出横向台阶。
顶部预览区域采用局部刷新，完整界面每 4 帧刷新一次；当前 SPI 约 12.5 MHz，
顶部预览平均约 10 帧/秒，完整界面约 2.5 帧/秒。
频谱页显示约 20～4000 Hz 的真实 FFT 能量柱，并叠加当前发声基频标记。
李萨如页使用当前音频与约 0.98 ms 延迟音频绘制实时 XY 轨迹。

## 操作

左 EC11：

- 转动：依次选择音色、音量、起音、衰减、持续、释音、弯音、揉音、滑音、拨弦、效果、八度；
- 按下：循环切换 `音频波形 → 实时频谱 → 李萨如 → 八路压力 → ADSR 包络`。

右 EC11：

- 转动：调节当前参数；
- 选中 `OCT` 后转动：切换 `0` 或 `+1` 八度；右旋钮按下可恢复到 `0`；
- 按下：恢复当前参数的默认值。

参数修改会立即作用于实际合成器。

### 音高表情

- 弯音：`-200～+200 cent`，每次转一格改变 10 cent，默认 0；
- 揉音：`0～50 cent`，内部由 5.5 Hz 正弦低频振荡器调制，默认 20；
- 滑音：`0～1000 ms`，每次转一格改变 10 ms，默认 80；
- 滑音为 0 ms 时立即达到新音高；大于 0 时会经过中间音高；
- 所有声部释放并完成释音后，弯音自动回到 0，避免下一次演奏跑调。

### 踏板复音

- 选中“音色”时，按右旋钮进入踏板模式，再按一次退出；
- 踏板模式中每次按键都会新增一个声部，松手后保持最后力度；
- 重复按同一个压力键会叠加同音高声部；
- 转动右旋钮只改变之后新触发声部的音色，旧声部保留原音色；
- 退出踏板后，踏板保持的声音进入正常 Release；
- 屏幕顶部显示 `踏板 ON 12/32` 形式的实时声部占用数。

### 拨弦

- 左旋钮转到“拨弦”，按右旋钮开启或关闭；
- 开启后右旋到底为 `ON`，左旋到底为 `OFF`；
- 按下任意实体键或手机虚拟键只发声一次，声音按“衰减”参数自然消失；
- 手一直按着也不会保持持续音，松开后可以再次拨同一根弦；
- 拨弦和踏板模式互斥，开启拨弦会退出踏板；
- 屏幕顶部显示“拨弦 ON”，包络页中的持续值显示为 `000%`。

### 实时频谱

- 使用 2048 点 FPGA FFT 和 Hann 窗分析真实混合音频；
- 每次采集约 41.9 ms，频谱最高更新率约 23.8 帧/秒；
- 显示约 20～4000 Hz，共 52 个对数频段；低频段更靠近屏幕中间，高频谐波也能完整显示；
- 青色柱表示真实频谱能量，橙色细线表示当前仍在发声的基频位置；
- 2048 点分辨率下相邻音节可能在能量柱中合并，八个基频标记仍会分别显示。

### 李萨如图形

- X 轴使用当前真实混合音频，Y 轴使用延迟 48 个采样点的同一音频；
- 使用约 0.98 ms 的固定音频延迟构成立体轨迹；
- 每帧采集 1024 个 XY 点，使用 96×96 正方形绘图区，并以 2×2 像素点绘制明亮轨迹；
- 根据上一帧峰值自动调整显示增益，小音量时轨迹仍然可见；
- 使用双缓冲点阵，避免绘制过程中出现半帧或闪烁；
- 自动增益只影响显示，不改变音频和频谱。

### 音频效果

- 效果参数位于滑音之后，右旋钮循环选择中文效果名称；
- 原声：不添加效果，逐样本直通；
- 延迟：约 120 ms 单抽头反馈延迟；
- 合唱：约 10 ms 短延迟，使用 0.8 Hz 调制；
- 混响：约 31/43/59/73 ms 四抽头反馈混响；
- 三种效果共用一条 8192 样本延迟 RAM，同一时间只启用一种；
- 效果切换时自动平滑干湿增益，所有显示与 I2S 都使用加效果后的最终音频。

### 蓝牙乐谱、按键映射与演奏回放

- 通过 JDY-31 SPP 接收一行一条的 ASCII 命令，可把手机中的文本乐谱直接
  粘贴到通用蓝牙串口 APK；
- 乐谱保存在 FPGA 内，断开手机后仍可播放；
- 内存最多保存 1024 个紧凑音符事件，事件保存时间间隔、时长、音、力度、
  音色和效果，不保存 PCM 音频；
- 八路压力键可以重新映射到 `0～7` 号音；
- 自定义 App 可从手机实时按下/松开八个虚拟琴键，并支持多指和弦；
- 每个虚拟琴键可保存名称、音高、力度、音色和效果；
- 实体压力键和手机虚拟键会合并发声，并一起写入录音；
- App 可选择按现有曲谱进行手动跟弹：按对当前音并松开后进入下一组，
  实体键和手机键都会参与错音判定；
- 演奏可录制为同样的事件格式，保持期间的最大压力会写回力度，再在 FPGA 上
  重新播放；
- 录音事件可以二进制回传到 App，还原为可编辑 NOTE、保存或重新发送回放；
- 乐谱播放时物理压力输入暂时停用，`STOP` 会释放所有播放音符并恢复输入。

### LED 演奏指示

J3 前四排预留了八路高电平点亮的 LED 输出，分别对应音符 `0～7`：

| 音符 | FPGA 引脚 | J3 引脚 |
|---|---|---|
| 0 | K2 | J3-1 |
| 1 | K1 | J3-2 |
| 2 | L1 | J3-3 |
| 3 | L2 | J3-4 |
| 4 | K4 | J3-5 |
| 5 | J4 | J3-6 |
| 6 | G1 | J3-7 |
| 7 | G2 | J3-8 |

接线方式为 FPGA 引脚接 LED 阳极，LED 阴极经限流电阻接 GND，公共地可接
J3-12。建议每路使用 `680 Ω～1 kΩ` 限流电阻。当前固件会在物理按键按下
或乐谱播放到对应音符时点亮 LED。

首次连接时，先把 JDY-31 按模块手册配置为 115200 bps：

```text
AT+BAUD8
```

手机配对 `JDY-31-SPP` 后可使用工程配套的“电子琴曲谱”App；发送曲谱时仍兼容
115200、8N1 的通用蓝牙串口 App。命令不区分大小写，支持 LF 或 CRLF；
成功回复 `OK`，查询回复 `PONG`，格式错误回复 `ERR`，1024 条事件已满回复
`FULL`。新版固件所有回复均以 CRLF 结尾。

```text
PING
VERSION
KEYSTATE
MAP 0,1,2,3,4,5,6,7
KEY DOWN 6,27,3,1
KEY UP 6
KEY ALL UP
SCORE CLEAR
NOTE 0,500,0,20,1,0
NOTE 250,500,2,20,1,0
NOTE 0,500,4,20,1,0
PLAY SCORE
STOP
REC START
REC STOP
REC PLAY
REC DUMP
TEST 32
TEST OFF
```

`VERSION` 返回 `VERSION 3`。`KEYSTATE` 返回 `KS XX`，表示映射后的八位实体
键状态。`KEY DOWN note,velocity,tone,effect` 控制单个手机
琴键，`KEY UP` 释放一个音，`KEY ALL UP` 释放全部手机琴键。

当前演奏指令覆盖比赛基础要求：

| 指令 | 操作方式 |
|---|---|
| 选音 | 八个压力键、`MAP` 重映射或手机虚拟琴键 |
| 触发 | 压力超过阈值后触发对应音符 |
| 力度 | MCP3008 压力值映射到发声音量 |
| 和弦 | 同时按下多个实体键或手机虚拟键 |
| 拨弦 | 开启“拨弦”后快速起音并按“衰减”自然消失 |

`REC DUMP` 在停止录音且没有播放时返回紧凑二进制包：

```text
A5 5A COUNT_HI COUNT_LO + COUNT × 4 字节大端事件
```

配套 App 负责校验数量、解码并转换为 NOTE 文本；通用串口 App 不适合直接读取
这部分二进制录音。

`TEST 32` 进入现场吞吐量验证模式：32 个独立振荡器同时工作，频率按两个 FFT
频点间隔排列，频谱测试页在中间区域显示 32 根彼此分开的柱峰；顶部显示
`ON 32/32`。
发送 `TEST OFF` 或 `STOP` 返回正常演奏模式。

`NOTE delta_ms,duration_ms,note,velocity,tone,effect` 中：

- `delta_ms` 为相对上一条音符开始的 `0～4095 ms` 间隔；
- `duration_ms` 为 `10～2550 ms`，按 10 ms 存储；
- `note` 为 `0～7`，`velocity` 为 `0～31`，`tone/effect` 均为 `0～3`；
- 和弦的首音使用正常间隔，其余同时开始音符的间隔写 `0`；
- 音色编号 `0～3` 对应“正弦、方波、锯齿、三角”，效果编号对应“原声、
  延迟、合唱、混响”。

`cent` 是音分，100 cent 等于一个半音。例如 +200 cent 正好升高两个半音，
-200 cent 正好降低两个半音。

## 接线

### EC11

| 信号 | FPGA 引脚 |
|---|---|
| EC11-1 A / B / 按压 | J8 / F6 / F7 |
| EC11-2 A / B / 按压 | J10 / J11 / H1 |

编码器公共端接地，输入使用内部上拉。

### LCD

| 信号 | FPGA 引脚 |
|---|---|
| SCLK | C11（J4-5） |
| MOSI | B11（J4-7） |
| CS | L5（J5-5） |
| DC/RS | K11（J5-7） |
| RESET | H5（J6-5） |
| 背光 | H8（J6-7） |

### JDY-31 蓝牙接口

FPGA 使用 115200 bps、8N1；模块必须与 FPGA 共地：

| JDY-31 引脚 | 连接 |
|---|---|
| VCC | J6-2，+3V3 |
| GND | J6-4，GND |
| TXD | J6-6，FPGA 引脚 J5，作为 FPGA RX |
| RXD | J6-8，FPGA 引脚 H7，作为 FPGA TX |

四针模块没有引出 `STAT`，因此界面不能可靠显示“已连接/未连接”状态；
需要确认连接时发送 `PING`，收到 `PONG` 即表示链路和 FPGA 均正常。

### MCP3008

| 信号 | FPGA 引脚 |
|---|---|
| SCLK | J7 |
| DIN | K7 |
| DOUT | L8 |
| CS | L7 |

### MAX98357A I2S

| 信号 | FPGA 引脚 |
|---|---|
| LRCLK | L10 |
| BCLK | K10 |
| DIN | K9 |

### 复位

板载 `S1` 复位输入为 `H11`，低电平有效。

所有外设使用 3.3 V 逻辑并与 FPGA 共地。

## 可调参数

主要参数位于 `src/electrophone.vhd` 顶部的 generic 区域：

- `G_SPI_HALF_CYCLES`：LCD SPI 分频；
- `G_ROT_FILTER_US`、`G_KEY_DEBOUNCE_MS`：EC11 滤波；
- `G_EDGES_PER_STEP`：编码器每格边沿数；
- `G_ENCODER1_REVERSE`、`G_ENCODER2_REVERSE`：编码器方向；
- `G_DEFAULT_*`：音色、音量和 ADSR 默认值；
- `G_DEFAULT_BEND`、`G_DEFAULT_VIBRATO`、`G_DEFAULT_GLIDE`：
  弯音、揉音深度和滑音时间默认值；
- `G_TIME_STEP_MS`：时间参数步进；
- `G_STATUS_MS`：恢复默认提示时间；
- `G_ADC_POLL_DIV`：MCP3008 通道轮询间隔，默认 1,000；
- `G_SENSOR_ON_LEVEL`、`G_SENSOR_OFF_LEVEL`：压力触发滞回阈值。
- `G_SENSOR_DEBOUNCE`：连续多少次采样超过阈值后才确认按下；
- `G_SENSOR_FILTER_SHIFT`：ADC 显示值的平滑强度，默认 3。

## 主要源码

- `src/sensor_scanner.vhd`：MCP3008 八通道扫描；
- `src/voice_allocator.vhd`：32 声部分配、踏板保持、同音叠加和最旧声部替换；
- `src/voice_state_ram.vhd`：32 声部相位、包络和音色状态 RAM；
- `src/synth_engine.vhd`：32 声部振荡、压力幅度、ADSR 和混音；
- `src/spectrum_analyzer.vhd`：2048 点 FFT、窗函数和双缓冲频谱结果；
- `src/spectrum_capture_ram.vhd`、`src/spectrum_work_ram.vhd`：FFT 采集与复数工作 RAM；
- `src/spectrum_tables.vhd`：由脚本生成的 Hann 窗和旋转因子表；
- `src/lissajous_scope.vhd`：48 样本延迟、自动增益和 XY 点帧生成；
- `src/lissajous_bitmap_ram.vhd`：96×96 双缓冲李萨如点阵；
- `src/audio_effects.vhd`：原声、延迟、合唱和混响效果处理；
- `src/effects_delay_ram.vhd`：8192 样本共享效果延迟 RAM；
- `src/uart_rx.vhd`、`src/uart_tx.vhd`：115200 bps 串口收发；
- `src/command_parser.vhd`：蓝牙文本命令解析和应答；
- `src/remote_input.vhd`：手机虚拟琴键状态、力度和每键音色/效果；
- `src/performance_mixer.vhd`：实体键与手机键合并、演奏/回放输入选择；
- `src/score_event_ram.vhd`：1024×32 位乐谱/录制事件 RAM；
- `src/score_sequencer.vhd`：乐谱时间线、和弦和虚拟压力门；
- `src/score_recorder.vhd`：演奏音符、力度、音色、效果和时长录制；
- `src/event_uploader.vhd`：录音事件二进制回传；
- `src/pitch_lut.vhd`：由脚本生成的音分倍率查表；
- `src/i2s_transmitter.vhd`：I2S 输出；
- `src/audio_scope.vhd`：双缓冲真实音频示波器；
- `src/ui_controller.vhd`：双 EC11 单屏交互；
- `src/wave_preview.vhd`：音频、频谱、李萨如、压力、包络五种预览；
- `src/color_ui_renderer.vhd`：中文彩色界面；
- `src/cjk_font_rom.vhd`：生成的中文 16×16 点阵字库。

## 当前限制

- 物理压力输入仍为八路，32 声部通过重复触发和踏板叠加形成；
- 2048 点 FFT 对最相邻音符的分辨率有限，主要依靠频谱柱与基频标记共同显示；
- 李萨如使用同一音频的延迟相位，属于相位轨迹图，不是两路独立乐器的 XY 合成；
- BSRAM、DSP 和 CLS 已接近器件上限，后续功能必须优先做资源优化；
- 事件 RAM 已占满全部 BSRAM，CLS 仅余 16 个，基本没有继续加功能的余量；
- `MAP` 重映射和乐谱只在本次上电期间有效；App 会在下次连接时自动重新下发映射；
- 四针 JDY-31 未接 `STAT`，只能通过 `PING/PONG` 判断链路；
- 录制保存的是演奏事件而不是 WAV；二进制回传由配套 App 解析；
- FPGA 只有一路全局效果器，不同手机琴键同时使用不同效果时以最后按下键为准；
- 乐谱播放中的音色/效果按音符开始事件切换，已经发声的旧声部保持原音色；
- LCD 采用“3 帧顶部预览局部刷新 + 1 帧整屏刷新”循环，顶部预览平均约 10 帧/秒；
- 设置断电后不保存。
